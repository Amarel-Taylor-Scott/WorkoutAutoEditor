==================================

Pipeline: ffprobe -> ffmpeg scene/silence detection -> local Gemma 4 (Ollama)
edit decision -> ffmpeg cut + concat. No cloud calls.

Environment for this run:
  - ffmpeg/ffprobe 7.0.2 (static) on PATH
  - Ollama serving model batiai/gemma4-e2b:q4  (a Gemma 4 e2b q4 build)
  - VIDCUT_MODEL=batiai/gemma4-e2b:q4
